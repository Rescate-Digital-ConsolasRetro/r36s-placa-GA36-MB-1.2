# Sistema Base Limpio — R36S (Placa GA36-MB V1.2) carpetas visibles

Imagen de sistema operativo restaurada y optimizada para consolas **R36S con placa modelo GA36-MB V1.2 (20260416)** y variantes compatibles.

## ¿Qué problema resuelve esta imagen?
En algunas unidades con revisión de placa **GA36-MB V1.2**, al conectar la tarjeta MicroSD a una PC con Windows las carpetas de usuario no aparecen visibles o el sistema pide formatear la unidad. 

Esta imagen base soluciona el arranque y habilita la estructura de particiones para que **Windows reconozca y muestre las carpetas directamente**, permitiendo gestionar tus propios archivos y respaldos sin errores.

## Características técnicas
* **Sistema limpio (Clean OS):** Se han eliminado todos los juegos y archivos multimedia comerciales; incluye únicamente el entorno base de arranque.
* **Compatibilidad de particiones:** Estructura ajustada para lectura directa de carpetas desde Windows.
* **Listo para restaurar:** Archivo comprimido en formato `.zip` que contiene la imagen `.img` lista para grabar en una tarjeta MicroSD nueva o formateada.

## Requisitos e instalación paso a paso
1. **Descarga** el archivo `.zip` desde el enlace superior y descomprímelo en tu PC con 7-Zip o WinRAR para obtener el archivo `.img`.
2. **Prepara tu tarjeta MicroSD** (se recomienda una memoria de buena calidad de 16 GB o superior). *Nota: este proceso borrará todo el contenido previo de la tarjeta.*
3. **Graba la imagen** utilizando una herramienta oficial como [Rufus](https://rufus.ie/es/) o [balenaEtcher](https://etcher.balena.io/).

4. **Inserta la MicroSD** en la ranura de sistema (TF1 / OS) de tu consola R36S y enciéndela para completar el primer arranque.
5. Una vez iniciada, apaga la consola desde el menú, extrae la MicroSD y conéctala a tu PC con Windows para comprobar que las carpetas ya son visibles.

para expandir la memoria utiliza diskgenius: https://www.diskgenius.com/
